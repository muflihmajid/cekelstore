# Roadmap Cekel Store v1.0

## Tujuan

Menguji apakah UMKM tertarik menggunakan katalog online yang langsung checkout ke WhatsApp.

## Fokus

Katalog produk + keranjang + checkout WhatsApp.

## Fitur Utama

### A. Halaman Toko Publik

Format:

```txt
cekelworks.com/toko/nama-toko
```

Isi halaman:

- Nama toko
- Logo/foto toko
- Deskripsi toko
- Nomor WhatsApp
- Jam buka
- Alamat singkat
- Link sosial media opsional
- Daftar produk
- Tombol checkout WhatsApp

### B. Katalog Produk

Setiap produk memiliki:

- Foto produk
- Nama produk
- Harga
- Kategori
- Deskripsi singkat
- Status tersedia/habis

### C. Kategori Produk

Admin bisa membuat kategori seperti:

- Makanan
- Minuman
- Paket hemat
- Frozen food
- Hampers
- Laundry
- Fashion
- Lainnya

### D. Pencarian Produk

Pelanggan bisa mencari produk berdasarkan nama.

### E. Keranjang Belanja

Pelanggan bisa:

- Menambahkan produk ke keranjang
- Mengubah jumlah produk
- Menghapus produk
- Melihat total belanja

### F. Checkout ke WhatsApp

Sistem membuat pesan otomatis:

```txt
Halo Kak, saya mau pesan:

1x Ayam Geprek - Rp15.000
2x Es Teh - Rp8.000

Total: Rp23.000

Nama:
Alamat:
Catatan:
```

### G. Admin Produk

Admin toko bisa:

- Tambah produk
- Edit produk
- Hapus produk
- Upload foto produk
- Mengatur harga
- Mengatur kategori
- Mengatur status tersedia/habis

### H. Profil Toko

Admin bisa mengubah:

- Nama toko
- Deskripsi toko
- Nomor WhatsApp
- Logo toko
- Jam buka
- Alamat singkat
- Warna tema toko

### I. Tema Warna Toko

Preset:

- Blue Teal
- Aqua Soft
- Ocean Blue
- Warm Clay
- Slate Premium

User tidak diberi input warna bebas di awal agar tampilan tetap rapi.

### J. QR Code Toko

Admin bisa mendapatkan QR Code toko untuk:

- Ditempel di warung
- Dipasang di kemasan
- Dibagikan di story WhatsApp
- Dipasang di Instagram
- Dicetak di brosur

### K. Statistik Dasar

Minimal:

- Jumlah kunjungan toko
- Jumlah klik checkout WhatsApp
- Produk yang paling sering diklik

### L. Branding Cekel Works

Untuk paket gratis, tampilkan branding kecil:

```txt
Dibuat dengan Cekel Works
```
